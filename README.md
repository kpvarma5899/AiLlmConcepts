| 1 | Vector databases | [questions/vector-databases](questions/vector-databases/README.md) | [src](questions/vector-databases/src) |

Each question folder holds three things:

- `README.md` is the problem: the design you defend, and the link to its page.
- `canvas.tsx` is the same note as a Cursor canvas, when the question was written from one.
- `src/` names the types. It is not a second design.

The sentence each note closes on:

1. **Vector databases.** If both vectors have length 1, cosine similarity, dot product, and Euclidean distance produce the same ranking. The identity is ‖a − b‖² = 2 − 2(a · b).

`docs/` is the site, generated by [`cache/canvas-to-pages.mjs`](cache/canvas-to-pages.mjs). Change a note, then run the renderer. Do not edit `docs/` by hand.
